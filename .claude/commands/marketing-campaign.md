# /marketing-campaign

Diseña una campaña de marketing end-to-end para Estudio Oro o Lobo Confitería.

## Uso

`/marketing-campaign [objetivo]` — ej: "captar 50 leads de derecho penal en CABA en 30 días"

## Output

1. **Brief estratégico**:
   - Objetivo SMART
   - Audiencia (perfil, ubicación, edad, intereses)
   - Mensaje central
   - Diferencial único (triple matrícula + corredor para Estudio Oro)
   - Plataformas (Meta Ads / Google Ads / LinkedIn / TikTok)
2. **Creatividades** (3 variantes A/B/C):
   - Hook (primer segundo / primer línea)
   - Cuerpo
   - CTA
   - Imagen sugerida (prompt para NanoBanana o Midjourney)
3. **Copy por plataforma**:
   - Meta: 125 chars headline + 30 char descripción + 40 char primary text
   - Google Ads: 30 char title + 90 char description
   - LinkedIn: 200 char intro + 600 char body
4. **Presupuesto**:
   - Total mensual sugerido
   - Distribución por plataforma
   - CPL esperado (Costo Por Lead)
5. **KPIs y métricas**:
   - Leads esperados
   - Conversión a cliente esperada
   - ROAS objetivo
6. **Compliance CPACF**: revisar que el copy cumpla con el Reglamento de Publicidad del CPACF (sin promesa de resultados, identificación del abogado).

## Reglas

- Marcá `[VERIFICAR]` cualquier benchmark que no esté confirmado.
- Para Lobo Confitería usá tono cálido / artesanal.
- Para Estudio Oro usá tono profesional / urgente / institucional.
