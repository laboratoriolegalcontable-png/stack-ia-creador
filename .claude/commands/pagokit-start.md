# /pagokit-start

Activando PagoKit para instalar el metodo de pago en este proyecto.

Ver instrucciones completas en `.claude/skills/pagokit/SKILL.md` y ejecutar el flujo de 5 fases:

1. Escanear el proyecto (framework, ORM, estructura existente)
2. Hacer las 3 preguntas de negocio al usuario
3. Seleccionar proveedor (Stripe / Mercado Pago / Wompi / Lemon Squeezy)
4. Generar los archivos usando plantillas de `.claude/skills/pagokit/REFERENCE.md`
5. Verificar los 5 candados de seguridad

Seguir exactamente las instrucciones de `.claude/skills/pagokit/SKILL.md`.
