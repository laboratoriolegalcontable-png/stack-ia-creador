# /generate-brief

Generador de briefs estructurados para cualquier iniciativa del Estudio Oro.

## Uso

`/generate-brief [tipo]` — donde tipo puede ser:
- `caso-legal` — brief de un caso nuevo para asignar al equipo
- `propuesta-comercial` — brief para armar propuesta a un cliente B2B
- `campana-publicitaria` — brief para creatividades / agencia
- `producto-digital` — brief para una nueva feature de OroGest / OMEGA / Escudo
- `contenido-viral` — brief para un video / post con potencial viral
- `evento` — brief para un evento (charla, networking, lanzamiento)

## Estructura universal del brief

1. **Resumen ejecutivo** — 3 líneas: qué, para quién, cuándo
2. **Contexto** — por qué lo hacemos ahora
3. **Objetivo** — SMART (específico, medible, alcanzable, relevante, temporal)
4. **Audiencia / cliente target** — perfil completo
5. **Mensaje clave** — 1 frase que resume todo
6. **Diferencial** — qué hace que ESTO sea distinto
7. **Entregables** — lista de outputs esperados
8. **Recursos necesarios** — equipo, presupuesto, herramientas
9. **Plazos** — milestones con fechas
10. **Métricas de éxito** — KPIs concretos
11. **Riesgos y mitigación** — qué puede fallar y plan B
12. **Aprobador final** — quién dice "go"

## Reglas

- 1 página máximo (legible en 3 minutos).
- Datos específicos, no generalidades.
- Si falta info crítica, marcala como `[REQUIERE INPUT]` y listala al final.
- Tono ejecutivo, sin floritura.
